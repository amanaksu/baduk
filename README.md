# 웹 바둑

브라우저에서 바로 두는 바둑입니다. 설치나 빌드 없이 `index.html` 하나로 동작합니다.

## 기능
- **2인 대전**: 한 기기에서 번갈아 두기
- **AI 대국**: 쉬움 / 보통 / 어려움 / 매우 어려움
  - 쉬움: 대부분 무작위, 가끔 좋은 수
  - 보통: 따내기·살리기·단수 등 수읽기 규칙 기반
  - 어려움 · 매우 어려움: 몬테카를로 트리 탐색(MCTS + RAVE). 매우 어려움은 생각 시간이 약 3배 깁니다.
- 9×9 / 13×13 / 19×19, 덤 0.5 / 6.5 / 7.5
- 패·자충수 금지, 무르기, 패스, 기권
- 양쪽 패스 시 자동 사석 판정 → 탭으로 수정 → 계가(집 + 따낸 돌 + 덤)
- 모바일 대응, "두 번 탭해서 착수" 실수 방지 옵션

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다 (예: `baduk`, Public).
2. `index.html`(필수)과 `README.md`를 저장소 최상단에 올립니다.
   - 웹에서: **Add file → Upload files** 로 끌어다 놓고 Commit
3. 저장소 **Settings → Pages** 로 이동
4. **Source: Deploy from a branch**, **Branch: `main` / `/ (root)`** 선택 후 Save
5. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속

## 참고
- AI 계산은 Web Worker에서 돌아가서 생각하는 동안에도 화면이 멈추지 않습니다.
- 설정은 브라우저에 저장되어 다음 접속 때 유지됩니다.
